# Website Index

> The registry of every page this repo has drafted. One block per page, keyword-map shape, no tables, ever. **A draft is not published** - it needs `/internal-linking` and `/publish` (and your go-ahead) before it's live. Content commands add blocks here; they never publish. It is a registry, not a journal: one-line notes only, build stories stay in chat.

Status: **Draft** (written, renders in preview) → **Linked** (`/internal-linking` wired it) → **Published** (live, in the sitemap, submitted)
