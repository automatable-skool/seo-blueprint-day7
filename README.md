# SEO Blueprint Pro

Rank your business on Google with Claude Code. 18 blueprints, one repo.

## Quick start

1. Download this folder (or clone it) anywhere on your computer
2. Open a terminal in the folder and run `claude`
3. Have a website? Type `/audit` - it scores your site immediately, no logins needed. Starting fresh? Type `/keyword-research`.

That's it. There's no setup step - each command walks you through exactly what it needs, the first time you run it.

## The unlock schedule

- **Days 1-7 (trial):** everything WITHOUT a 🔒 - the complete fix + launch layer. Score your site, fix it to 100%, ship real pages.
- **🔒 Day 7 (first billing):** the machine vault - the builders and compounders below.
- **Month 2 (day 30):** tracking + optimization commands, marked Month 2.

## The path (run them in this order - it mirrors the course)

| Step | Command | What it does |
|------|---------|--------------|
| 1 | `/audit` | Have a site? Start here: Semrush audit → fix everything → 100% Site Health. No site yet? Skip to 2 |
| 2 | `/keyword-research` | Keywords + clusters → your build map (the pyramid). Map runs dry later? Re-run with `expand`: 10 roots → 1,000 keywords |
| 3 | `/build-website` → `/publish` → `/gsc` | 🔒 Day 7 · The pyramid built AND live the same day, then Search Console set up manually (all clicks) |
| 4 | `/context-layer` | The context layer - proof + voice in one pass. Every other command reads it |
| 5 | `/blog-post` | The blog engine - one publish-ready draft per run |
| 6 | `/service-page` | The money pages. Runs before `/gbp` on purpose - your Business Profile's products and services need pages to link to |
| 7 | `/seo-optimization` | Optimize: on-page, technical, images, speed, AI overviews |
| 8 | `/gbp` | Business Profile setup, citations campaign included |
| 9 | `/gbp-posts` | The GBP posting system |
| 10 | `/review-generator` | 🔒 Day 7 · The review machine: filter form on your site, GHL save-workflow wired, reply drafts |
| 11 | `/internal-linking` | 🔒 Day 7 · Wire everything into the hub-and-spoke graph |
| 12 | `/proposal` | Win the client: a finished proposal on your own domain, ready to send. Fill in `context/business.md` once and every future proposal prices itself |
| 13 | `/scale-map` | 🔒 Day 7 · The month-1 finale: build + optimize + publish EVERY page left in the map |

**Around the path** (run when needed):

| Command | What it does |

## Requirements

- [Claude Code](https://claude.com/claude-code) installed
- A website (or the intent to build one - `/build-website` handles that)
- Semrush - powers the audits + all keyword data. [Start with the 14-day free trial](https://www.semrush.com/partner/jonocatliffseo_7401436/?irclickid=UodwPVRilxyZWxsygXUph16GUkr03ZTt3xLWws0&irgwc=1&afsrc=1) - two weeks is enough to build your whole keyword map
- Optional: Google Search Console access (for `/gsc`)
- WordPress users: the Novamira plugin + connection (lets Claude edit your site directly) - the first WordPress command you run walks you through it
